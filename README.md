# 🧮 Calculator Web Application

A responsive and interactive **Calculator** built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations through a clean, modern, and user-friendly interface.

## 📌 Project Overview

This calculator application enables users to perform fundamental mathematical operations including addition, subtraction, multiplication, and division. It features a responsive design, real-time display updates, and keyboard support for a smooth user experience.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📟 Interactive display screen
- 🗑️ Clear and reset functionality
- ⚡ Real-time input and result display
- ⌨️ Keyboard support
- 📱 Responsive design for all screen sizes
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling and responsive design
- **JavaScript (ES6)** – Calculator logic and event handling

## 🎮 Usage

- Click the calculator buttons to enter numbers and operators.
- Press **C** to clear the display.
- Press **=** to calculate the result.

### Keyboard Shortcuts

| Key | Action |
|------|--------|
| `0-9` | Enter numbers |
| `+ - * /` | Arithmetic operations |
| `Enter` | Calculate result |
| `Backspace` | Delete last character |
| `Escape` | Clear display |
